# Skill and code-reference policy

Tools and skills are independent external content. Review before applying; no remote code or service is executed just by adding a reference to this file.

Official Stellar: https://skills.stellar.org
OpenZeppelin: https://github.com/OpenZeppelin/openzeppelin-skills/tree/main/skills/setup-stellar-contracts
DeFindex: https://raw.githubusercontent.com/paltalabs/defindex-sdk/main/defindex-sdk-skill.md (deferred; vault operations not part of corridor MVP)
Tukar: https://github.com/PugarHuda/tukar (design/architecture/security reference; never copy its crypto contracts without license/security evaluation)

## Review gates
Check upstream commits and license, SDK version, target network and security claims. Never automatically run an installation script or remote code during a money-movement workflow. SDK compatibility evidence must come from tests, not marketing claims.
